# CloudOps AI

AI-powered cloud incident intelligence platform.

## Vision

CloudOps AI helps engineers investigate application and cloud infrastructure
incidents by correlating telemetry, deployments, GitHub activity, and
technical documentation.

## Goals

- Collect real application telemetry
- Detect operational incidents
- Correlate incidents with deployments and code changes
- Investigate incidents using AI
- Provide evidence-backed root cause analysis
- Recommend remediation steps
- Provide a public and useful cloud operations platform

## Technology

- Next.js
- FastAPI
- PostgreSQL
- Redis
- OpenTelemetry
- Docker
- GitHub Actions
- AI / RAG
- AWS
